# Exemples de la unitat 1

Classes: `FitxersText`, `DadesBinaries`, `FitxersXml`, `FitxersJson` i `CsvIProperties`. `App` és el llançador.

Executeu `./gradlew run` per veure el catàleg. Exemple:

```bash
./gradlew run --args='json-objecte'
```

Les dades són en `app/dades/` i la configuració en `app/config/`.
